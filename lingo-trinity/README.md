# LINGO Trinity Hub

Static JavaScript recovery prototype combining That’s My Lingo, Kotton’s Code, and Loyalty Lane Apparel.

Run from repository root:
```sh
npx --yes serve lingo-trinity -p 4173
npm --prefix lingo-trinity test
```

No Worker, Firebase, Shopify, payment, account, or production integration. Demo credits and XP are local-only, have no cash value, and cannot be redeemed or cashed out. No real-money wagering, purchase, checkout, or prize redemption. Kotton’s Code uses child-friendly fictional content and excludes private family details. Apparel pricing and fulfillment are unverified. G02 remains protected; production remains HOLD.
