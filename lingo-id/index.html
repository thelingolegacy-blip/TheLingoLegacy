LINGO ID Account Readiness

No identity provider is currently verified for this public account surface. LINGO ID is an architecture and UI scaffold; it is not an active login, account, or session service.

Firebase is the intended identity integration path for the current platform architecture. A dedicated non-production Firebase project and matching Web app must be verified before staging sign-in can be enabled. Production identity remains gated separately.

Integration status

  • Identity provider: not verified for this surface
  • Firebase staging project and Web app: verification required
  • Cloudflare Worker identity routes: not accepted
  • Session persistence and logout: not accepted
  • Secrets: must remain in approved secret management, never source

Required account flows

  • Sign-in and sign-out
  • Verified callback and token validation
  • Session creation, refresh, expiry and revocation
  • Account/profile landing and recovery
  • Protected-route authorization and tenant isolation

Remain disabled

  • Public login and registration controls
  • Wallet and rewards mutations
  • Registered game play and persistent progression
  • Commerce, billing and payment unlocks
  • Child accounts pending privacy and safety review

Future LINGO ID scope

  • Profile and preferences
  • XP, badges and loyalty status
  • Game progress and session recovery
  • Community and creator identity
  • Account security and recovery controls

Required verification

  • Dedicated staging tenant and exact project ID
  • Token issuer, audience and signature checks
  • Desktop and mobile browser tests
  • Session persistence, expiry and logout tests
  • Privacy, security and accessibility review

Platform guardrails

  • GitHub remains source of truth
  • Cloudflare is the intended edge runtime
  • Vercel is retired from the target production architecture
  • No production Firebase credentials in staging
  • No secret values in the repository or public manifest

Account features will be enabled only after the identity service, security rules, session lifecycle, privacy review and release evidence are accepted.
