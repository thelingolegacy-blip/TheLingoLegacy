Session Test Checklist

Run this checklist only after login, callback, logout, and session state are implemented.

Desktop

  1. Open login route
  2. Complete Auth0 redirect
  3. Return to callback
  4. Render signed-in state
  5. Logout clears state

Mobile

  1. Repeat Safari/Chrome login
  2. Check redirect loop
  3. Check session persistence
  4. Check logout

Do not test yet

  • Child accounts
  • Billing unlocks
  • Wallet writes
  • Rewards redemption
