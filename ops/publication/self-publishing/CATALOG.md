# LINGO Self-Publishing Catalog

## Scope

Register the current owner-controlled publication pipeline for all known LINGO books and games.

Registration is not publication. Each title must independently progress through:

PUBLICATION-READY -> SUBMITTED -> APPROVED -> LISTED -> COMMERCIALLY PUBLISHED

## Publication boundary

Catalog registration, source creation, release packaging, or upload readiness does not establish submission, approval, listing, or commercial publication.

No game or book is represented as commercially published unless its specific state has independently verified evidence.
