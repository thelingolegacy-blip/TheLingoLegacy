## Silver Key progression

The supplied completion page introduces the Silver Key as a non-monetary learning achievement.

Silver Key = learning/completion badge.

It must not be represented as cash, currency, gambling value, or a financial instrument.

The Silver Key Club QR area should route to an age-appropriate parent/caregiver-controlled experience when implemented. Any live URL/QR destination requires its own verification before publication.
