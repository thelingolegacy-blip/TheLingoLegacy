# LINGO Studio Control Plane

## Mission
Coordinate continuous studio development across repository, CI, deployment, design, media, voice, video, and game surfaces without collapsing governance boundaries.

## Continuous Loop
SOURCE → CHANGESET → VALIDATE → TEST → SECURITY → EVIDENCE → VERIFY → ACCEPT → AUTHORIZE → MERGE → POST-MERGE VERIFY

## Provider Federation
- GitHub: canonical repository/control surface for current LINGO repository work.
- GitLab: beta federation lane; no accessible LINGO project is currently exposed to the connected account.
- AppDeploy: deployment/build/QA surface; READY is not equivalent to production authorization.
- Canva: design/media creation and asset management surface.
- Product Design: UX research, design QA, and implementation review surface.
- Media: voice, explainer video, images, animation, and game-production surfaces remain governed creative inputs/outputs.

## Agent Operating Contract
Agents may inspect, reason, propose, repair branches, run available validation, create evidence, request/prepare merges, and report failures. Agents may not self-authorize production promotion or bypass an unmet gate.

## State Establishment
ESTABLISHED(T+1) ⇔ P(T+1) ∧ E(T+1) ∧ V(T+1) ∧ A(T+1)

Each operand is independently established. Prior state never substitutes for current state.
