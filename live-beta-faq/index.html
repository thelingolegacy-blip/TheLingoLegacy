Live Beta FAQ

Is checkout live?

No. Billing is intentionally skipped for this wave. Browse and give feedback only.

What should testers try?

Homepage, Living Universe, That’s My Lingo, Loyalty Lane Apparel preview, KottonsCode, release notes, and contact/feedback paths.

How should issues be reported?

Send route, device, browser, expected result, actual result, and screenshot or video if possible.

What blocks launch?

Production outage, broken core routes, inaccessible policy/contact pages, security concerns, or repeated mobile blockers.
