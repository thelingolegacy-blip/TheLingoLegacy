Provider Handoff Checklist

Use this page when moving from Vercel-side tracking into external provider dashboards. It records what must be confirmed, not secret values.

Auth0 handoff

  • Confirm production callback URL
  • Confirm logout return URL
  • Confirm allowed web origins
  • Run session smoke test after route implementation

Shopify handoff

  • Choose the production resource
  • Connect it to the Vercel project
  • Confirm products, variants, tax, shipping, and receipts
  • Do not enable public checkout CTAs until QA passes

Exa handoff

  • Confirm feature owner and use case
  • Provision resource only if retrieval/search is needed
  • Add env name to contract after provisioning
  • Document rate/usage guardrails

Stripe handoff

  • Billing remains skipped
  • Confirm live products and prices in Stripe
  • Verify webhooks, receipts, failures, and refunds
  • Update Vercel env names only after live QA

Firebase handoff

  • Confirm production project
  • Audit rules and storage permissions
  • Verify backups and environment separation
  • Only then connect public config names

DNS handoff

  • Review Vercel Domain Connect recommendation
  • Apply Cloudflare changes only from domain-specific guidance
  • Re-check SSL and aliases after DNS propagation
