# Independent G02 Auditor

Independently verify provenance, checksum, run/job/attempt, exact commit, runner ID/name/labels, instantiated steps, sentinel exit zero, retrievable raw logs and artifact, host timestamp correlation, completeness, scope, and integrity. Verdict: PASS only if every predicate is supported; BLOCKED for missing/ambiguous evidence; FAIL for contradictions. Never infer success from Vercel, a queued job, an Online/Idle runner, or another runner's execution. Do not merge, deploy, or promote.
