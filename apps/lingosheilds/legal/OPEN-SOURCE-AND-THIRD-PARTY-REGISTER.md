# Open Source & Third-Party Register

Before a public or commercial release, inventory every external dependency and service.

Required fields:
- component
- version
- license
- source
- direct/transitive
- modification status
- attribution requirement
- redistribution requirement
- security status
- commercial-use restriction
- approval status

Special review categories:
- Claude/model provider terms
- GitHub terms/API limits
- GitLab terms/API limits
- Cloudflare terms
- Firebase terms
- npm packages
- Flutter/Dart packages
- container images
- CI actions
- fonts/media/assets
- generated AI content

No dependency should be represented as legally cleared until its actual license/terms have been reviewed.
