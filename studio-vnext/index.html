Architecture principles

Security and operability are part of the product.

Identity first

Single Lingo ID concept with per-service authorization; no shared admin tokens in clients.

Contract-driven

Versioned APIs, schema validation, typed events, and backward-compatibility tests.

Fail closed

Unknown gate state, missing credentials, or incomplete evidence blocks promotion.
