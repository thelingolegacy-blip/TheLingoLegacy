# LINGO Unity Game Track

Unity is the optional engine track for LINGO projects that need a dedicated real-time 2D/3D pipeline.

Current policy:
- Unity Personal: free for eligible creators under the current $200,000 USD financial threshold.
- Unity Pro: required above that threshold for gaming/entertainment use.
- Console publishing requires the applicable Unity Pro/platform-holder path.

Project policy:
1. Unity projects are separate from the Cloudflare web runtime.
2. Game source is version-controlled.
3. Build outputs are evidence-bearing artifacts.
4. No Unity build becomes production merely because it compiles.
5. QA, acceptance, deployment authorization and live validation remain independent.
6. LINGO demo/virtual economy rules remain separate from real-value payment infrastructure.

Initial Unity candidates:
- That's My Lingo 3D
- LINGOarcade
- LINGO World
- Kotton's Code interactive world

A real Unity build must be produced and independently verified before runtime availability is claimed.
