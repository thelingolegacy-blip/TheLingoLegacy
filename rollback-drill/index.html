Rollback Drill

Operator checklist for restoring the last stable Vercel deployment if the live beta reveals a launch blocker.

Trigger

  • Production outage
  • Core route broken
  • Security concern
  • Policy/contact inaccessible

Steps

  1. Identify last stable deployment
  2. Pause public posting
  3. Rollback through Vercel deployment history
  4. Verify homepage and launch routes
  5. Post update in Launch War Room

After rollback

  • Log root cause
  • Patch on branch
  • Re-run static validation
  • Resume tester wave only after ready
