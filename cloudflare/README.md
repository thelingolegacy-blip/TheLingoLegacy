# Cloudflare Studio Build

This directory contains the non-production Cloudflare Workers build artifact for The Lingo Legacy studio shell.

- Source of truth: GitHub
- Runtime target: Cloudflare Workers
- Visual system: Crimson / White / Shadow Noire
- askLINGO: included
- Production Worker: unchanged
- Canonical domain routing: unchanged

This artifact is intentionally isolated from the production Worker until build/runtime evidence satisfies the project acceptance gates.
