# Universe Hub & Mobile Landing Pages — Design Preview

This isolated design preview adds a responsive Universe Hub concept for The Lingo Legacy without replacing the current homepage or changing production.

## Preview
- `design-previews/universe-hub/index.html` — responsive homepage, destination cards, sections for Worlds, Learn, Play, Create, Stories, Apparel, Media, Community, and askLINGO.
- Mobile bottom navigation, responsive card grids, inline SVG/CSS artwork, emoji icon set, semantic landmarks, and accessible status messages.
- CTA links scroll to sections. Product/feature links and email signup intentionally show preview-only messages; they do not create accounts, accept payments, store email, or call production APIs.

## Integration plan
1. Review the preview and design system.
2. Connect destination cards to approved canonical landing routes and real service integrations.
3. Build dedicated pages for each approved product/brand in a follow-up PR.
4. Integrate the same IA and visual tokens into the Flutter app navigation shell.
5. Run accessible/mobile QA and route/link checks before release.

No production homepage, worker, DNS, app deployment, or live integration is modified by this preview.
