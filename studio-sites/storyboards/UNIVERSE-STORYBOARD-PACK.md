# LINGO Universe — Storyboard Pack v0.1
Status: development drafts; creator approval, canon review and asset rights review required.

## Shared episode grammar
1. Cold open: a striking visual question.
2. World reveal: visual motif, sound palette and immediate stakes.
3. Inciting choice: two or three meaningful options.
4. Skill beat: teach one mini-game mechanic, then test it.
5. Consequence: choice changes dialogue, trust, lore or a collectible.
6. Resolution / cliffhanger: clear outcome and next objective.
7. Stinger: optional teaser with captions and audio description.

Each scene record needs scene_id, chapter_id, purpose, location, characters, beat, dialogue, shot/camera, motion, sound cue, UI overlay, branch flags, accessibility notes, asset IDs, rights status and acceptance status.

## Kotton’s Code — The Missing Word
Audience: family-friendly. Pillars: WORD, HEART, FRIENDSHIP, DREAM, LEGACY.
- S01 Workshop / morning: a glowing word tile disappears from the Code Map. Macro shot; gentle paw tap.
- S02 Code Garden: Azora finds a torn note, a quiet friend and gold pawprints. Player chooses the first clue.
- S03 Mini-game: match word tiles to picture clues. Wrong answers provide hints.
- S04 Friendship Bridge: Zay Zay chooses whether to rush or help a character cross. Helping sets a HEART story flag.
- S05 Memory Tree: reassemble the missing word using clues; collaboration resolves the scene.
- S06 Stinger: another tile lights up — LEGACY.
Shots: wide garden reveal; low-angle pawprint trail; close-up clue choices; over-shoulder puzzle; helping two-shot; push-in on map.
Sound: warm marimba, paw taps and short success chime; captions and mute option.
