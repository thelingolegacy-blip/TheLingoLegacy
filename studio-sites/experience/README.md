# LINGO Nexus Studio Experience

Interactive static vertical slice for LINGOarcade and LINGOslots. Includes ten world records; 30 original character concepts; 20 chapter outlines; 30 missions; CSS-generated animated world visuals; opt-in procedural Web Audio; and local mission completion/reset feedback. No account, wallet, network or backend writes.

## Run locally
Serve the repository root with a static HTTP server and open `/studio-sites/experience/`. The page fetches `../config/experience-bible.json`; direct `file://` loading may block this request.

## Release status
Studio preview only. Final character art, sprite sheets, animation exports, scored music, voice performances, full game mechanics, browser/mobile QA, security, rights review, backend integrations, acceptance and production authorization remain separate gates.
