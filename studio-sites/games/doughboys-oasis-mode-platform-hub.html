API, identity & token boundary

Frontend

Device adapter → input map → game state → accessible UI. Store only demo progress locally in this prototype.

Backend (planned)

Authenticated API validates identity, mode, round results, partner consent and progression server-side.

Access tokens

Short-lived user access tokens belong in secure platform storage; refresh/revoke via identity provider. Never ship service-role keys or private API secrets in HTML, Flutter assets, TV packages or Git.

Integrity

Server validates race result submissions, idempotency keys, partner creation and story-event schema. Local client state is never authoritative for ranked play.
