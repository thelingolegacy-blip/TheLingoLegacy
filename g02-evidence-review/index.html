3
Sentinel succeeds

Steps must exist and the sentinel must complete with exit status 0.

4
Logs retrievable

Open the original GitHub job and verify real execution logs.

5
Artifact integrity

Download the original artifact and verify its SHA-256 sidecar.

6
Host telemetry correlated

Host-side service/process/listener output must match the run, job, and commit.

7
Independent review

A reviewer must validate the source, hashes, correlation, and every predicate.

What is still missing?

Host telemetry is not available through the public Actions record

This page cannot inspect /opt/actions-runner, start the daemon, retrieve private host logs, or prove the machine is polling. It will not guess those values. The host report must be collected on the actual Linux machine and then reviewed alongside the GitHub run.

Why the gate stays blocked

A queued or cancelled job with runner_id 0, an empty runner name, no steps, or no verified artifact is not a successful sentinel. A green-looking page or static checklist is not acceptance evidence.

Safety boundary: read-only public GitHub API requests only. This page does not dispatch or rerun workflows, change repository files, alter runner settings, deploy, or promote production. API rate limits or unavailable endpoints are shown as unknown—not as PASS.
