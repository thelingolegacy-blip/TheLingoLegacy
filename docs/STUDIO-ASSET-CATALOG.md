# Studio Asset Catalog Contract

Every production asset receives: stable logical name, platform owner, asset class, source/provenance, dimensions/aspect ratio, format, accessibility description where applicable, licensing/provenance status, cache policy, content hash and intended route/component.

Recommended tree:

assets/brand/
assets/icons/
assets/platforms/<platform>/
assets/characters/
assets/environments/<platform>/
assets/products/
assets/motion/
assets/audio/ui/
assets/audio/ambience/
assets/audio/media/
assets/backgrounds/
assets/illustrations/

No production screen should reference anonymous or untracked assets.
