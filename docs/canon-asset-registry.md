# Canon and Asset Registry

These files are non-secret source-of-truth contracts:

- `config/canon/canon-registry.json`
- `config/design/design-tokens.json`
- `config/icons/icon-registry.json`
- `config/assets/asset-registry.json`

They prevent drift in names, colors, icons, character roles, asset ownership, usage locations, licensing status, and production status. They do not replace real asset storage, legal review, or dashboard verification.
