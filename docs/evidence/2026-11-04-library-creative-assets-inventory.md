## Canon and release guardrails

1. Use canonical names: LINGOarcade (not LINGOarena), Crazy Weasols (not Crazy Weasel), and no star symbol in product names.
2. Keep each product's identity distinct. Do not flatten the canonical LINGO tree into generic “Lingo World” branding.
3. Use the Kotton character guide as a reference for the actual Kotton mascot; the temporary SVG in the current branch is a placeholder concept, not the approved final mascot artwork.
4. Keep licensed third-party characters out of public builds unless rights are documented.
5. Keep mature OASIS domains and story themes behind an appropriate content-rating and age-gating review before public release.
6. Keep artwork, audio, animation and video status separate: storyboard != final image asset; cue sheet != audio export; concept board != playable game; preview deployment != production release.
7. When binary source art is imported, record the Library file, source version, checksum, license/ownership, crop/derivative, target path, responsive variants, alt text, and independent rendering check.
