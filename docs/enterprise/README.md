## File placement rules

- Cross-platform governance and enterprise operations: `docs/enterprise/`.
- Sweepstakes product, legal controls and campaign-specific rules: `docs/sweepstakes/`.
- Game-specific mechanics and content: `studio-sites/games/<product>/` or the existing canonical game file.
- Shared creative assets and design tokens: `studio-sites/assets/` and existing design-system docs.
- Runtime source remains with its owning application/service.
- Evidence, release records and acceptance artifacts remain in the established operations/release evidence locations.

Do not duplicate authoritative content across folders. Link to the canonical source and record version/status. Do not move or overwrite existing canonical documents without reviewing their ownership and references.
