## Current operating facts
- The production web runtime is Cloudflare Worker/edge.
- The G02 runner host and successful assignment must be proven with actual host/GitHub evidence.
- A draft infrastructure scaffold is not a provisioned host or cluster.
- Kubernetes and the virtual bottleneck are future isolated capacity-lab work, not production dependencies.

## Page ownership

Update the relevant page in the same pull request as the code or workflow it describes. Keep facts evidence-backed, record the last verification date, and never publish secrets or unredacted diagnostic output.
