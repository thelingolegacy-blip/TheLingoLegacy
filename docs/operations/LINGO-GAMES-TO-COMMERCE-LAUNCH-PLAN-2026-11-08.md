Date: 2026-11-08
Status: active planning baseline; staging-first; not a launch certificate or authorization for live gambling, live payments, production routing or unverified deployment.
Canonical source: thelingolegacy-blip/TheLingoLegacy

## Executive objective
Create one connected LINGO entertainment, retail and community ecosystem. Sequence: (1) That's My Lingo and unified game portfolio, (2) Kotton's Code cartoon world, (3) Loyalty Lane streetwear world and commerce, (4) Loyalty Lane Cycle, (5) integrated community app plus Enterprise/Studio/Engineering worlds. Measure acquisition, activation, retention, conversion, contribution margin and support quality. No customer count, revenue or income is guaranteed.

## Wave 1 — That's My Lingo flagship + unified game lobby
Portfolio: That's My Lingo; Spades Is My Lingo; UhNo Lingo U-NO; Lingo Lions: Eruptions; Cashman Lingo Mania; Tricia's Escape; Doughboy Oasis; Crazy Weasols; Silly in Philly: The Streets; Jersey Shore & the Undead. Preserve each game's canon, mechanics, art and status independently.
Build one polished account/lobby experience: sign-up/sign-in/recovery; player profile/avatar; game catalog and launch; favorites/recent games; cross-game identity; events/missions; XP/achievements; leaderboards with anti-cheat; social/friends with privacy controls; accessible settings; support; session controls; clear balances and transaction history.
Economy: Demo Coins, Loyalty Bucks and Lingo Tokens need separate definitions and permitted uses. Use non-redeemable demo credits by default. Any connected wallet must use server-authoritative balances, append-only ledger, idempotency, atomic writes, reconciliation, abuse controls and audit logs. No cash-out or peer-to-peer transfer.
DraftKings/FanDuel-style means polished account, lobby, events, stats, rewards and store UX—not copied branding or unapproved real-money wagering. No sportsbook, deposits, odds, cash prizes, jackpots, cashout or sweepstakes activation in this plan.
Monetization: verified physical apparel sales; approved cosmetic/content purchases only after checkout and compliance review; sponsorship only with advertiser/privacy controls; memberships only with clear benefits and cancellation terms. Track qualified visits, registrations, first game, completed sessions, D1/D7 retention, store click-through, conversion, refunds and support.
Acceptance: each game status accurate; shared account journeys tested; gameplay playable on target mobile/web; persistence reliable; currency never client-authoritative; privacy/consent reviewed; test-mode payments only until approved; independent QA evidence.

Brand direction: Industrial Noir / Crimson Shadow; crimson, black, white and gold; premium editorial imagery; consistent LL/Loyalty Lane identity; product storytelling; mobile-first storefront; fit/size guide; collections; product pages; shipping/returns/FAQ; email capture; support; accessible checkout.

## Wave 5 — Integrated community app + Enterprise/Studio/Engineering worlds
Community: opt-in profiles; interest spaces; friends/following; moderation/report/block; age-appropriate controls; events; polls; creator feeds; local markets; store and laundry links; support; notification preferences; privacy controls; anti-spam and abuse response. Enterprise Control Center: portfolio/operations visibility. Studio Hub: content, assets, product configuration and release approvals. Engineering: source, build, test, API, environment and deployment evidence. Share product registry, role model, audit log and evidence references—not privileged production secrets in browser clients.
Architecture: GitHub canonical source; Cloudflare authoritative edge; Firebase remains intended backend pending project identity/rules reconciliation; Supabase project must be assigned an explicit role or isolated; shared API contracts; provider adapters; correlation IDs; consent-aware analytics; monitoring; backups/restore; RBAC; feature flags and staged releases.
Acceptance: verified identity journey, role separation, API contracts, cross-product links, data boundaries, moderation/privacy controls, backup/restore evidence, device/browser tests, independent QA and rollback readiness.

## Customer and revenue journey
Discover game/story/brand content → visit landing page → select experience → opt-in account → complete first meaningful action → relevant follow-up → return for next session/service/drop → optional purchase of verified physical goods or approved services → support → repeat/referral. Keep funnels and consent separate by product. Never use children's content profiles for commerce targeting.

## Launch scorecard
Acquisition: qualified visits, attribution, opt-in conversion, cost per acquired customer where paid channels are used.
Activation: account completion, first game completed, first episode watched, first product viewed, first service booking.
Engagement: session completion, D1/D7/D30 retention, repeat sessions, community participation.
Commerce: add-to-cart, checkout conversion, AOV, gross margin after fulfillment/fees, refunds/chargebacks, repeat purchase.
Operations: crash-free sessions, API errors/latency, support response, fulfillment/service SLA, moderation response, build/deploy success.
Set numeric targets after baseline measurement; never fabricate growth rates or guarantee income.
