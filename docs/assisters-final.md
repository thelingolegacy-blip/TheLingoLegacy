# LINGO Assisters — Final Product Contract

LINGO Assisters is the coordinated intelligence workforce of The Lingo Legacy.

## Flagship roles
- LINGOscout — discovery, reconnaissance, current research, resources and dependencies.
- askLINGO — user-facing conversation, voice, research, generation, learning and governed educational modes.
- LINGOrefined — analysis, cleanup, optimization, normalization, UI/UX and release-candidate refinement.
- LINGO Host Assister — physical-host observation and diagnostic assistance.
- LINGO Control Assister — assignment, orchestration, dependency and matrix coordination.
- LINGO Evidence Assister — evidence collection and correlation.

## Mission
INTENT → MISSION → ASSIGN → DISCOVER → ASSIST → REFINE → EXECUTE → PROVE → VERIFY → ACCEPT → ESTABLISH → DELIVER → REPORT.

## Boundaries
Capability is not authority. Configuration is not execution. Execution is not verification. No Assister may invent runner IDs, logs, transactions, approvals, evidence, or gate status.

## Game strategy
Unity is an optional game engine for LINGO projects requiring a dedicated 2D/3D pipeline. Unity Personal is currently free for eligible creators under Unity's current $200,000 financial threshold. Web-first games remain independent of the Unity pipeline.

## Finalization
The pages and contracts establish the design/build layer. Runtime deployment, API credentials, live integrations, production activation, and gate PASS remain independently evidence-gated.
